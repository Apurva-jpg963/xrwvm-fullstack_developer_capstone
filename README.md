## Overview
This is the IBM Full Stack Software Developer Capstone Project (`fullstack_developer_capstone`).
A national car dealership web application that allows users to view dealership branches across the United States, browse reviews, and post reviews with sentiment analysis.

### Technologies Used
- **Frontend**: React, JavaScript, HTML5, CSS3, Bootstrap
- **Backend**: Python, Django, SQLite
- **Microservices**: Node.js, Express, MongoDB (Dealerships and Reviews service)
- **Sentiment Analyzer**: Python, Flask, IBM Watson NLP
- **DevOps**: Docker, Kubernetes, GitHub Actions CI/CD, IBM Cloud Code Engine
